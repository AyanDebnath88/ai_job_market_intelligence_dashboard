# Global AI Talent Intelligence Platform 


## business problem 
Understanding compensation and hiring patterns in the AI workforce

## Dataset 
50000+ AI job postings from 2020-2026

## Tools 
- Python 
- Power BI 
- SQL

### Methodology 

- Data Cleaning 
- Feature Engineering 
- Explortatory Analysis 
- Dashboard Development 

## Key Findings 
1. Senior Remote Roles command higher compensation 

2. Entry level remote positions earn less on average

3. Experience level is a stronger salary driver than role family 

4. Compensation is relatively consistent across AI role categories
